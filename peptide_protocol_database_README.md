# Peptide protocol database

Source: 61 distinct peptide protocols listed at https://peptidedosages.com/single-peptide-dosages/, reviewed July 18, 2026.

The CSV consolidates vial-size variants into one peptide record. Ranges and cycle guidance are transcribed or compactly normalized from the site’s protocol page; the source URL is retained per record. Entries expressed as weekly, intranasal, topical, or animal-research protocols are explicitly labeled rather than converted to a daily human-equivalent amount.

This is a research reference, not medical advice. Many listed compounds are investigational, and the site itself advises consultation with a qualified healthcare professional.
